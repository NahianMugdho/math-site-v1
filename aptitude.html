১Simplification কী ও পরীক্ষায় কেন গুরুত্বপূর্ণ

Simplification হলো একটি জটিল গাণিতিক রাশিকে ধাপে ধাপে সহজ করে মান বের করা। ব্যাংকের Quantitative Aptitude-এ এটি সবচেয়ে বেশি ও সবচেয়ে দ্রুত করার মতো অংশ, তাই এখান থেকেই সময় বাঁচানো যায়। প্রশ্ন সাধারণত দুই ধরনের:

ধরনপ্রশ্নে যা থাকেকী করবেন
Exact value“What will come in place of ?”সঠিক মান বের করুন, অপশনের শেষ অঙ্ক দিয়ে যাচাই করুন
Approximation“approximate value”, “not expected to calculate exact value”সংখ্যাকে কাছের সহজ সংখ্যায় এনে হিসাব করুন
মূল কৌশলSimplification-এ জাদু নেই — BODMAS, নামতা/বর্গ/ঘন মুখস্থ আর শর্টকাট গুণ-ভাগ। এই তিনটি ঠিক থাকলে প্রতি প্রশ্নে ৩০–৪০ সেকেন্ডই যথেষ্ট।

সতর্কতাভাগ ও গুণের মধ্যে “গুণ আগে” — এটি ভুল ধারণা। দুটির অগ্রাধিকার সমান, বাম থেকে ডানে করতে হবে। যোগ-বিয়োগেও একই। বন্ধনীর আগে ঋণচিহ্ন থাকলে ভেতরের সব চিহ্ন উল্টে যায়: −(a − b) = −a + b।

ঘাতের সূত্র

aᵐ × aⁿ = aᵐ⁺ⁿ          aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ             (ab)ⁿ = aⁿbⁿ
a⁰ = 1                  a⁻ⁿ = 1 / aⁿ
a^(1/n) = ⁿ√a           a^(m/n) = (ⁿ√a)ᵐ

বীজগাণিতিক সূত্র

(a + b)² = a² + 2ab + b²        (a − b)² = a² − 2ab + b²
a² − b² = (a + b)(a − b)        a² + b² = (a + b)² − 2ab
(a + b)² + (a − b)² = 2(a² + b²)
(a + b)³ = a³ + 3a²b + 3ab² + b³
a³ + b³ = (a + b)(a² − ab + b²)   a³ − b³ = (a − b)(a² + ab + b²)

ধারার যোগফল

1 + 2 + … + n          = n(n + 1) / 2
প্রথম n টি বিজোড় সংখ্যা = n²
প্রথম n টি জোড় সংখ্যা   = n(n + 1)
1² + 2² + … + n²       = n(n + 1)(2n + 1) / 6
1³ + 2³ + … + n³       = [n(n + 1) / 2]²

Surd-এর সূত্র

√a × √b = √(ab)         √a / √b = √(a/b)
(√a + √b)(√a − √b) = a − b
(√a + √b)² = a + b + 2√(ab)

হর মূলদীকরণ:
1 / (√3 + √2) = (√3 − √2) / (3 − 2) = √3 − √2
1 / (√5 − 2)  = (√5 + 2) / (5 − 4)  = √5 + 2
শেষ অঙ্ক দিয়ে চেনাপূর্ণবর্গ সংখ্যার শেষ অঙ্ক কখনও 2, 3, 7, 8 হয় না। ঘনের শেষ অঙ্ক: 2→8, 3→7, 7→3, 8→2 (বাকিগুলো একই থাকে: 0,1,4,5,6,9)।

৮Approximation টেকনিক

  1. প্রতিটি সংখ্যাকে কাছের সহজ পূর্ণ সংখ্যায় গোল করুন (49.98 ≈ 50, 20.03 ≈ 20)।
  2. মূল (√) থাকলে কাছের পূর্ণবর্গ নিন (√120.91 ≈ 11)।
  3. BODMAS মেনে হিসাব করুন।
  4. উত্তর অপশনের সবচেয়ে কাছেরটি বেছে নিন, সঠিক মান মেলানোর দরকার নেই।
49.98 × 20.03 ÷ 5.01
≈ 50 × 20 ÷ 5 = 200        (আসল মান ≈ 199.8)

8.07 × 11.02 + √120.91 + 33.03
≈ 8 × 11 + 11 + 33 = 132
সতর্কতাখুব বেশি আগেই গোল করবেন না। অপশনগুলো কাছাকাছি (যেমন 121, 122, 124) হলে বড় সংখ্যাকে আরও সঠিকভাবে গোল করতে হবে। অপশন দূরে দূরে থাকলে মোটামুটি গোল করাই যথেষ্ট।

৯“?” বের করার ধাপ (Missing number)

56² + 43² − ? = 4700
3136 + 1849 − ? = 4700
4985 − ? = 4700
? = 4985 − 4700 = 285

নিয়ম: ? কে একপাশে নিয়ে যান, চিহ্ন বদলে যায় (+ ↔ −, × ↔ ÷)।
ঘাতের সমীকরণে ভিত্তি এক করুন:
(16)⁹ ÷ (16)⁴ × (16)³ = (16)?   →   9 − 4 + 3 = 8   →   ? = 8

১০উত্তর যাচাই ও সময় ব্যবস্থাপনা

  • শেষ অঙ্ক যাচাই: পুরো গুণ না করে শুধু শেষ অঙ্কের গুণফল মিলিয়ে অপশন বাদ দিন।
  • Digit-sum (৯ দিয়ে ভাগশেষ): 47 × 23 = 1081 → (4+7)=11→2, (2+3)=5, 2×5=10→1; 1+0+8+1=10→1 ✔ মিলেছে। (অঙ্ক এদিক-ওদিক হলে ধরা পড়ে না।)
  • সময়: প্রতি প্রশ্নে গড়ে ৩০–৫০ সেকেন্ড। কোনো প্রশ্ন ১ মিনিটের বেশি লাগলে চিহ্ন দিয়ে পরে আসুন।
  • ক্রম: আগে Level 1 (সহজ) প্রশ্ন, শেষে ভারী গুণ-ভাগ।
