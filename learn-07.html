৭. Concepts 8, 9: Real Number, Number Line, Absolute Value, Reciprocals

  • The set of real numbers (বাস্তব সংখ্যা) includes all integers (positive and negative) and all numbers in between, such as fractions and decimals. They have a natural ordering represented by the number line (সংখ্যারেখা).

  • All real numbers correspond to a point on the number line, which is infinitely long in both directions.

  • Any number left of zero is negative; any number right of zero is positive.

  • The further left a number is, the smaller it is; the further right, the greater.

  • For any two numbers, the one to the left is less than (ক্ষুদ্রতর) the one to the right; the one to the right is greater than (বৃহত্তর) the one to the left.

  • The absolute value or modulus (পরম মান) of a number is its numerical value (সাংখ্য মান) without regard to sign. |3| = 3 and |−3| = 3.

  • Absolute value can be thought of as the distance from zero. Distance can never be negative, so absolute value can never be negative.

  • For any number a and positive number b: |a| = b ⇒ a = b or a = −b.

  • a/b and b/a are inverses or reciprocals of each other. When two reciprocals are multiplied, the answer is 1.

Useful number facts

  • n × 1 = n; n/1 = n; n/n = 1 (n ≠ 0); 1ⁿ = 1

  • n ± 0 = n; n × 0 = 0; 0/n = 0; 0ⁿ = 0

  • 1 × 1 = 1; 1/1 = 1

  • n/0 = undefined (অসংজ্ঞায়িত)

  • Generally, multiplying two positive integers gives a larger product. But when two numbers between 0 and 1 are multiplied (or an integer is multiplied by a number between 0 and 1) the product is smaller. E.g. 0.5 × 0.4 = 0.2, and 0.2 < 0.4 < 0.5. If 0 < x < 1 and 0 < y < 1, then xy < x and xy < y.

  • 0 is a multiple of every integer.

  • 1 is a divisor of every integer.

  • The square or cube of a positive integer is bigger than the integer itself (2² = 4). But the square or cube of a number between 0 and 1 is smaller than the number itself: (0.5)² = 0.25, (0.5)³ = 0.125. If 0 < x < 1, then x > x² > x³.
