৮. Concept 10: Exponents, Square, Cube, Square Root, Cube Root

  • Exponents (powers) are shorthand for repeated multiplication. 3⁴ = 3 × 3 × 3 × 3 = 81 (read "3 to the power 4").

  • Exponent 2 is called square: 5² = 25. Exponent 3 is called cube: 5³ = 125.

Laws of exponents

Rule Example
xᵃ · xᵇ = xᵃ⁺ᵇ 2³ × 2⁵ = 2⁸ = 256 (caution: xᵃ + xᵇ ≠ xᵃ⁺ᵇ)
(xᵃ)ᵇ = xᵃᵇ (2³)² = 2⁶ = 64
(xy)ᵃ = xᵃ · yᵃ (2y)² = 2² · y² = 4y²
(x/y)ᵃ = xᵃ / yᵃ (x/3)³ = x³/27
xᵃ / xᵇ = xᵃ⁻ᵇ 2⁶ / 2³ = 2³ = 8
x⁻ᵃ = 1/xᵃ 3⁻² = 1/3² = 1/9; 3⁻¹ = 1/3
x⁰ = 1 5⁰ = 1, 9⁰ = 1
x¹ = x 5¹ = 5

Roots

  • A square root of a positive number N is a real number which, when squared, equals N. √16 = 4 because 4² = 16; also (−4)² = 16. All positive numbers have two square roots that differ only in sign.

  • A cube root of N is a real number which, when cubed, equals N. ∛27 = 3 because 3³ = 27.

  • The square of a real number can never be negative, so negative numbers have no (real) square roots. (−5)² = 25, √25 = ±5.

  • For positive a and b: √(a×b) = √a × √b and √(a/b) = √a / √b.

  • For positive a and n: a1/n = ⁿ√a.

  • The cube of a real number can be negative, so negative numbers can have cube roots. (−5)³ = −125, ∛(−125) = −5.
