১০. Useful Algebra Formulae

These are the most common maths in competitive exams. They test your ability to juggle numbers, form equations and solve using basic mathematical operations.

  • a² − b² = (a + b)(a − b)

  • (a + b)² = a² + 2ab + b²

  • (a − b)² = a² − 2ab + b²

  • a² + b² = (a + b)² − 2ab

  • a² + b² = (a − b)² + 2ab

  • (a + b)² = (a − b)² + 4ab

  • (a − b)² = (a + b)² − 4ab

  • (a + b)³ = a³ + 3a²b + 3ab² + b³

  • (a − b)³ = a³ − 3a²b + 3ab² − b³
