১৬. Concept 19: Time & Distance

  • Speed is the distance traveled per unit of time (একক সময়ে অতিক্রান্ত দূরত্ব).

    • Speed = Total distance / Total time

    • v = d/t; d = v × t; t = d/v (v = speed, d = distance, t = time)

  • If the speed from A to B is x km/hr and the speed returning from B to A is y km/hr, the average speed = 2xy/(x + y).

    • Because speed = total distance / total time = (d + d) / (d/x + d/y) = 2d / (d(x + y)/xy) = 2xy/(x + y).

  • 1 km/hr = 5/18 m/s.

  • Boat and current problems are a variation of speed problems. If the boat's speed is x km/hr and the current's speed is y km/hr:

    • Downstream (স্রোতের অনুকূলে): speed = (x + y) km/hr.

    • Upstream (স্রোতের প্রতিকূলে): speed = (x − y) km/hr. (The source page prints (x + y) here by mistake.)
