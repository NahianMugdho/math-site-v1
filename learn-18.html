১৮. Concept 21: Set

  • A Venn diagram is a graphical representation of sets. A set is a collection of well-defined distinct objects.

  • Union (A ∪ B): the set where all elements of set A and set B are present. If A = {1, 2, 3} and B = {2, 3, 4, 5, 7}, then A ∪ B = {1, 2, 3, 4, 5, 7}.

  • Intersection (A ∩ B): the set where only the common elements of A and B are present. With the same sets, A ∩ B = {2, 3}.

  • A very important formula: n(A ∪ B) = n(A) + n(B) − n(A ∩ B), where n(set) = number of elements in the set.
