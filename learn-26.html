২৬. Chapter 5: Coordinate Geometry

  • Cartesian grid: two perpendicular axes (number lines) crossing each other — a horizontal x-axis and a vertical y-axis. Their meeting point is the origin. The axes divide the plane into four quadrants.

  • The position of any point on the plane is found with this grid: drop perpendiculars from the point to the x-axis and y-axis; the foot on the x-axis gives the x value and the foot on the y-axis gives the y value, so the point is written (x, y). The quadrant decides the signs of x and y.

    • Example: point B has x = 2 and y = −2, so B = (2, −2).

  • Midpoint of A(x, y) and B(x′, y′): ((x + x′)/2, (y + y′)/2).

    • Example: A(2, 4) and B(6, −2) → midpoint = ((2 + 6)/2, (4 + (−2))/2) = (4, 1).

  • Distance between A(x, y) and B(x′, y′): √((x − x′)² + (y − y′)²).

    • The source's worked example (labelled A(0, 2) and B(6, −2)) actually computes √((8 − 0)² + (17 − 2)²) = √(8² + 15²) = 17, which corresponds to the points (0, 2) and (8, 17). For A(0, 2) and B(6, −2) as labelled, the distance would be √(36 + 16) = 2√13.
