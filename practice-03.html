⚡ Shortcuts and techniques

  • aᵐ·aⁿ = aᵐ⁺ⁿ; aᵐ/aⁿ = aᵐ⁻ⁿ; (aᵐ)ⁿ = aᵐⁿ; a⁰ = 1; a⁻ⁿ = 1/aⁿ. Make the bases equal first, then equate exponents.

  • (a+b)² = a² + 2ab + b²; (a−b)² = a² − 2ab + b²; a² − b² = (a+b)(a−b); a³ + b³ = (a+b)³ − 3ab(a+b).

  • a² + b² = (a+b)² − 2ab; x + 1/x = k → x² + 1/x² = k² − 2; x − 1/x = k → x² + 1/x² = k² + 2.

  • Rationalise: 1/(√a − √b) = (√a + √b)/(a − b).

  • Nested roots: √(k + √(k + …)) = x where x² = k + x.

  • Know squares to 30 and cubes to 12; bracket a non-perfect square between two perfect squares.
