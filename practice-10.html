⚡ Shortcuts and techniques

  • Speed = distance/time. For a fixed distance, speed and time are inversely proportional (speed ratio a : b → time ratio b : a).

  • km/hr → m/s multiply by 5/18; m/s → km/hr multiply by 18/5.

  • Average speed for equal distances at x and y = 2xy/(x + y). For equal times it is (x + y)/2.

  • Train crossing a pole or man: time = length / speed. Crossing a platform: (train + platform) / speed.

  • Two trains: opposite directions relative speed = sum; same direction = difference. Distance to cover = sum of lengths.

  • Boats: downstream = b + c; upstream = b − c; still-water speed = (down + up)/2; current = (down − up)/2.

  • Late/early problems: distance = (speed₁ × speed₂/(difference in speeds)) × time difference.

  • Races: use the ratio of distances run in the same time.
