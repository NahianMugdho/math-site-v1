⚡ Shortcuts and techniques

  • If A does a job in a days, A's one-day work = 1/a. Together: 1/a + 1/b; time = ab/(a + b).

  • LCM method: take total work = LCM of the days; each person's efficiency = work/days. Add efficiencies for teamwork.

  • If A is k times as efficient as B, A takes 1/k of B's time.

  • Man-days: M₁D₁/W₁ = M₂D₂/W₂ (more men → fewer days).

  • Wages are shared in the ratio of work done (efficiency × days).

  • Pipes: inlets add, outlets subtract. A leak makes the net rate = fill rate − leak rate.

  • Three pair-rates: A + B + C = (sum of the three pair rates)/2.
