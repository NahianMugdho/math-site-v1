⚡ Shortcuts and techniques

  • n(A∪B) = n(A) + n(B) − n(A∩B). Only A = n(A) − n(A∩B). Neither = total − n(A∪B).

  • Three sets: n(A∪B∪C) = n(A) + n(B) + n(C) − n(A∩B) − n(B∩C) − n(A∩C) + n(A∩B∩C).

  • A set with n elements has 2ⁿ subsets, 2ⁿ − 1 proper subsets (excluding the set itself), and nCr subsets of size r.

  • Minimum overlap = n(A) + n(B) − total. Maximum overlap = the smaller set.

  • Inequalities: add or subtract the same number freely. Multiplying or dividing by a negative number flips the sign.

  • |x − a| < b means a − b < x < a + b. |x − a| > b means x < a − b or x > a + b.

  • For a quadratic inequality, factorise and test the intervals between roots. Count integers carefully (strict vs inclusive ends).
