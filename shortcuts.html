🔢 Number & Algebra · আরও শর্টকাট
Divisibility (3, 9, 4, 8, 6) 3/9: digit sum divisible by 3/9 ; 4: last two digits ; 8: last three digits ; 6: divisible by both 2 and 3
Divisible by 7 Remove the last digit and subtract twice it from the rest; repeat. 343 → 34 − 6 = 28 ✔
Product of consecutive integers Product of n consecutive integers is divisible by n! (e.g. n(n+1)(n+2) is divisible by 6)
Square via nearby numbers a² = (a − b)(a + b) + b² ; e.g. 27² = 24 × 30 + 9 = 729
a + 1/a = k a² + 1/a² = k² − 2 ; a³ + 1/a³ = k³ − 3k
Three-variable identities a² + b² + c² − ab − bc − ca = ½[(a−b)² + (b−c)² + (c−a)²] ; if a + b + c = 0 then a³ + b³ + c³ = 3abc
Quadratic equation ax² + bx + c = 0 Sum of roots = −b/a ; product = c/a ; discriminant D = b² − 4ac
AP / GP nth term = a + (n−1)d ; Sₙ = n/2 [2a + (n−1)d] ; GP sum = a(rⁿ − 1)/(r − 1)
Number series Check: difference → difference of differences → × or ÷ pattern → squares / cubes ± a number
📊 Arithmetic · Bank Aptitude
Average New average after adding x to n numbers = (nA + x)/(n+1) ; average of first n natural numbers = (n+1)/2, first n odd = n, first n even = n + 1
Average of an AP / consecutive numbers (first + last)/2 = middle value
Average speed (equal times) (x + y)/2 — equal distances use 2xy/(x+y)
Splitting in a ratio Total T in m : n → mT/(m+n) and nT/(m+n)
Combining ratios a : b = 2 : 3 and b : c = 4 : 5 → make b equal (LCM 12) → a : b : c = 8 : 12 : 15
Partnership Profit share ∝ capital × time
Mixture / replacement After n replacements of x from Q, remaining = Q(1 − x/Q)ⁿ
“More” and “less” percent A is a% more than B → B is 100a/(100+a)% less than A ; A is a% less than B → B is 100a/(100−a)% more than A
Up x% then down x% Net loss = x²/100 % (+20% then −20% → −4%)
Fraction ↔ percent 1/6 = 16.67% · 1/7 ≈ 14.29% · 1/9 = 11.11% · 1/11 = 9.09% · 1/12 = 8.33% · 1/16 = 6.25%
Successive discounts d₁ + d₂ − d₁d₂/100 ; e.g. 20% and 10% = 28%
Faulty weight Gain % = error / (true value − error) × 100 ; e.g. 900 g for 1 kg → 100/900 = 11.11%
Articles bought vs sold If CP of x articles = SP of y articles, profit % = (x − y)/y × 100 ; CP of 15 = SP of 12 → 25%
Simple interest — multiples If a sum becomes n times in T years, R = (n − 1)/T × 100 %
Compound interest Doubling time ≈ 72 / r years ; 3-year CI − SI = P(r/100)²(3 + r/100)
Time & work M₁D₁H₁/W₁ = M₂D₂H₂/W₂ ; efficiency ∝ 1/time
Pipes & cisterns A fills in a, B empties in b (b > a) → both open: ab/(b − a)
Boats & streams Still-water speed = (downstream + upstream)/2 ; stream speed = (downstream − upstream)/2
Trains Pole / man: L/v ; platform: (L + P)/v ; opposite directions: (L₁ + L₂)/(v₁ + v₂) ; same direction: (L₁ + L₂)/(v₁ − v₂)
Speed ratio Same distance: speed ratio a : b → time ratio b : a
Calendar — odd days Ordinary year 1, leap year 2 ; 100 years = 5, 200 = 3, 300 = 1, 400 = 0
Clock — in 12 hours Hands coincide 11 times, point opposite 11 times, make a right angle 22 times
Handshakes / arrangements n people shake hands n(n−1)/2 times ; arrangements with repeats n!/(p! q! r!)
Probability basics n coins → 2ⁿ outcomes ; two dice → 36 outcomes, P(sum 7) = 6/36 = 1/6
Three sets n(A∪B∪C) = n(A) + n(B) + n(C) − n(A∩B) − n(B∩C) − n(A∩C) + n(A∩B∩C)
